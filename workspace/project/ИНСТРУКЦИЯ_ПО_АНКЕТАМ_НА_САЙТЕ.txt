════════════════════════════════════════════════════════════════
0. СЛОВАРЬ: ЧТО ЕСТЬ ЧТО В КОНСТРУКТОРЕ
════════════════════════════════════════════════════════════════
БЛОК        — карточка с вопросом и кнопками-ответами (№ виден в списке
              «Блоки схемы» и в заголовке редактора «Блок №N»).
ОТВЕТ       — строка в редакторе: подпись кнопки + фрагмент + следующий
              блок + флаги. Игрок видит ответы как кнопки.
ФРАГМЕНТ    — кусок текста будущей анкеты. В конце пути все фрагменты
              пройденных ответов склеиваются вокруг шапки и подвала.
NEXT        — «следующий блок» у ответа: куда вести после нажатия.
              Пусто — у ядерных блоков следующий по ядру, у прочих ФИНИШ
              и сборка шаблона.
AFTER       — «показывать блок только после ответа»: блок-надстройка,
              вставляется сразу после триггерного ответа, а по завершении
              возвращает анкету на основную линию.
ЯДРО        — список блоков, обязательных для самописного героя, в порядке
              опроса (поле «Ядро: id блоков…» + чипы «+ №N»).
КОРЕНЬ      — стартовый блок анкеты (селект «Корневой блок»).
ФЛАГИ       — чекбоксы «канон» / «самописный» ТОЛЬКО у ответов корневого
              блока: «канон» завершает путь и пингует проверяющих,
              «самописный» запускает ядро.

3.2. Поле «Ядро: id блоков в порядке опроса»: впиши «2» или кликни чип

3.3. Селект «Корневой блок»: выбери «№1: Кем ты подаёшься?».
3.4. Кнопка «Сохранить настройки» → вспышка «Настройки досье сохранены.

4. ШАПКА, ПОДВАЛ, ДОПУСКИ, КАНАЛЫ
════════════════════════════════════════════════════════════════
4.1. Поле «Шапка шаблона (плейсхолдер {user})»: вставь текст ЯДРА из md:
       АНКЕТА ПЕРСОНАЖА — {user}
       † ── Имя персонажа ── † …  ── Снаряжение ── † (все семь строк ядра)
     {user} подставится именем игрока при сборке.
4.2. Поле «Подвал шаблона»: строки-инструкция из md («Опишите характер,
     внешность и предысторию… Готовую анкету опубликуйте в этом канале…»).
4.3. «Категория приватных каналов» — категория, где бот создаст канал анкеты.
4.4. «Роль проверяющих» — роль, которой бот пингует о выдаче шаблона и о каноне.
4.5. «Роль допуска каноничных героев» и/или «Минимальный ранг для канона»:
     оставь 0/пусто — канон открыт всем; задай роль или ранг — канон только
     через допуск (достаточно одного из двух).
4.6. Чекбокс «Включить анкеты» → «Сохранить настройки».
4.7. В Discord: /анкета панель channel:#канал-объявлений → публикация панели
     с кнопкой «Создать анкету».
4.8. Карточка «Правила анкет» (r44, отдельная форма под настройками модуля):
     текст, который бот отправляет игроку в канал анкеты СРАЗУ ПОСЛЕ её
     формирования — на самописном пути после выдачи шаблона, на каноничном
     после завершения блоков (до пинга проверяющих). Чекбокс «Отправлять
     правила после формирования анкеты» выключает отправку, не трогая текст;
     пустой текст — тоже ничего не отправляется. «Сбросить к заводским» —
     вернуть эталон из ПРАВИЛА_АНКЕТ.md (без декоративных символов, только
     разделители ═). Длинный текст бот сам режет на сообщения по лимиту
     Discord 2000 знаков; вспышка сохранения показывает число сообщений.
     В Discord состояние и превью показывает /анкета правила (админ),
     параметр send_rules:true/false — быстрый вкл/выкл отправки.

5. НЕОБЯЗАТЕЛЬНЫЕ НАДСТРОЙКИ (AFTER) — КОГДА НУЖНЫ
════════════════════════════════════════════════════════════════
5.1. After применяй для дополнительных вопросов, которые нужны ТОЛЬКО при
     определённом ответе. Пример: блок «Санкция и дисциплины» с after
     «после ответа „Псайкер Империума“ (блок №3)»: он вставится сразу после
     выбора псайкера и после финиша вернёт игрока на основную линию.
5.2. Как выставить: редактор нового блока → селект «Показывать блок только
     после ответа» → нужная пара «подпись (блок №N)» → «Сохранить блок».
5.3. Ограничения: after на собственный блок или цикл next/after не сохранятся
     (вспышка «Цикл переходов: блоки …»); блок с after не нужен в ядре.

════════════════════════════════════════════════════════════════
6. РЕДАКТИРОВАНИЕ БЕЗ ПЕРЕЗАГРУЗКИ (памятка по интерфейсу)
════════════════════════════════════════════════════════════════
6.1. «+ ответ» добавляет строку локально, «× строку» убирает; индексы флагов
     пересчитываются сами. Можно добавить хоть 20 строк за один заход.
6.2. «Сохранить блок» сохраняет БЕСШОВНО: обновится только карточка редактора,
     страница не мигает и не прыгает наверх; вспышка скажет результат.
6.3. Остальные формы (настройки, правила анкет, создание блока, удаление)
     перезагружают страницу целиком — это норма.
6.4. Красные вспышки и что они значат:
     «у блока нет ни одного ответа» — добавь хотя бы одну подпись ответа;
     «ответ без подписи» — пустая подпись в одной из строк;
     «дубликат подписи …» — две одинаковые подписи в блоке;
     «ответ … ведёт в несуществующий блок» — next указывает на удалённый блок;
     «зависимость „после …“ указывает на несуществующий ответ» — битый after;
     «Цикл переходов: блоки …» — схема зациклилась, разорви next/after;
     «Блок занят как корневой / в ядре / ссылаются ответы / в активной анкете»
       — сначала убери зависимость, потом удаляй блок;
     «Кнопка не из этой формы …» — дай странице догрузиться и повтори;
     «Сбой сохранения: ТипИсключения: текст» — пришли текст вспышки и хвост
       консоли разработчику.

7. ТЕСТОВЫЙ ПРОГОН (обязательно после сборки)
════════════════════════════════════════════════════════════════
7.1. Самописный: кнопка «Создать анкету» → «Самописный герой» → сторона →
     фракция → приходит шаблон: шапка с ядром и именем, фрагмент фракции,
     подвал; следом — сообщения с правилами анкет (r44); в канал падает пинг
     проверяющих; канал остаётся открытым.
7.2. Канон: «Каноничный герой» → путь завершён сразу, правила анкет (r44),
     пинг проверяющих (или отказ с причиной, если допуск не пройден — так и
     должно быть).
7.3. Штаб: «Должность штаба» → должность → штабная мини-анкета.
7.4. /анкета список — активные анкеты; /анкета шаблон — повтор шаблона;
     удаление канала анкеты вручную закрывает сессию (r38), лимита нет.
7.5. Архив анкет виден внизу вкладки «Досье» (последние 8 записей).
