# Сообщения-инструкции для игроков (стиль скопирован с обновлений когитатора)

Каждый блок — готовое сообщение для Discord (лимит 2000 знаков соблюдён,
длины указаны в заголовках). Публиковать по порядку, первым — с пингом роли.

## Сообщение 2 (уровни и прогрессия, ~700 знаков)

```
⚙ Уровни и прогрессия — путь познания
- Пишите в каналах прогрессии: каждое засчитанное сообщение даёт опыт и дата-коги Бога-Машины.
- Чем полнее сообщение, тем щедрее награда: пост на лимит символов приносит полную ставку, короткие реплики — меньше. Кулдауна нет: усердие ценнее скорости.
- Ранги с 1 по 100. Каждый ранг повышает множитель валюты: чем выше познание, тем дороже каждое слово.
- За ранги выдаются роли познания; при повышении прежняя роль ранга снимается — носите только одну печать звания.
- Команды: /ранг — ваш прогресс, слова и баланс; /топ — десятка лучших кузни.
- Ветки и посты форумов считаются так же, как обычные сообщения: ролевые простыни в темах работают на ваш ранг.
```

## Сообщение 3 (цитаты, ~620 знаков)

```
📜 Книга литаний — голос кузни
- Когитатор сам публикует каноничные цитаты Ереси Хоруса и Империума 40k в каналах, где идёт живой диалог: активность будит автопубликацию.
- Ваша строка может попасть в книгу: /цитаты предложить text:… author:… source:… — после проверки администратума цитата встанет в ротацию.
- /цитаты случайная — случайная литания прямо сейчас, для настроения и споров о каноне.
- Цитаты — не просто украшение: это атмосфера наших сводов и след живой истории сервера.
- Предложения проходят модерацию: одобренное входит в книгу, отклонённое остаётся в очереди — спамять предложениями не нужно.
```

## Сообщение 4 (магазин и инвентарь, ~700 знаков)

```
⚒ Магазин и инвентарь — дата-коги в деле
- /магазин список — витрина лавки кузни; /магазин купить item:№ — покупка за дата-коги.
- Покупки падают в инвентарь: /инвентарь — страницы кнопками ◀ ▶, выбор предмета и «Использовать предмет».
- Применение предмета шлёт стилизованное сообщение в канал и пингует администратум: хранители кузни видят эффект и применяют его по уставу.
- Дата-коги приходят за сообщения, ранги, рейтинг и розыгрыши — а уходят здесь: планируйте траты, машина не любит должников.
- Цены и состав лавки меняет администратум; следите за витриной после обновлений.
```

## Сообщение 5 (капсулы-рулетки, ~660 знаков)

```
⚱ Капсулы реквизиции — рулетка кузни
- /лутбоксы список — ларцы реквизии и цены; /лутбоксы состав box:№ — содержимое и шансы дропа.
- /лутбоксы открыть box:№ — вскрытие за дата-коги: шансы работают как веса, машина честна, как арифметика Марса.
- Дроп падает в инвентарь наравне с покупками: дальше /инвентарь и «Использовать предмет».
- Капсула — самый быстрый путь обратить дата-коги в реликвию… или в пыль. Машина решает, вам — жать кнопку.
- Нулевой шанс не ломает вскрытие: предмет с шансом 0 просто не выпадает никогда.
```

## Сообщение 6 (розыгрыши, ~600 знаков)

```
🎁 Жребий конклава — розыгрыши
- Розыгрыш объявляется отдельным сообщением: жмите кнопку «🎉 Участвовать» под ним — кнопка переживает даже перезапуск бота.
- /розыгрыши список — активные жребии и точное время окончания.
- В срок машина тянет победителей сама: призы уходят в инвентарь или на баланс, объявление — с упоминаниями счастливцев.
- Одно нажатие — одна заявка: повторно жать не нужно, машина помнит каждого участника и не даёт дублей.
- Досрочно завершить или отменить жребий может только администратум: не просите тянуть быстрее, таймер неумолим.
```

## Сообщение 7 (рейтинг активности, ~700 знаков)

```
🏆 Рейтинг активности — циклы дня и недели
- Рейтинг считает XP и сообщения отдельно от вашего ранга: дневной цикл закрывается в полночь, недельный — в понедельник.
- /рейтинг день и /рейтинг неделя — текущие таблицы; /рейтинг архив — итоги закрытых циклов с наградами.
- На границе цикла лидеры получают дата-коги по таблице наград, а в канал анонсов прилетает пьедестал с итогами.
- В зачёт идут только каналы прогрессии (включая ветки и форумы); действует порог сообщений за цикл — защита от накрутки.
- Ушедшие с сервера и роли-исключения в таблицы не попадают: рейтинг честен, как счётчик когитатора.
```

## Памятка публикующему

- Порядок: 1 → 7; между сообщениями — пауза в пару секунд, чтобы Discord не склеил.
- Пинг роли только в первом сообщении (как в образцах обновлений).
- При изменении механик правьте соответствующее сообщение и уточняйте номер обновления в шапке первого.
