# Как загрузить в бота (шпаргалка конструктора)

- ЯДРО — блок «Ядро», входит в ядро конструктора (обязателен для самописных).
- Корень: «Каноничный / Самописный» → блок «Сторона» с тремя ответами:
  Империум / Хаос / Ксеносы; next каждого ответа — свой блок выбора.
- Блоки выбора: «Фракция Империума» (16 ответов), «Сторона Хаоса» (7 ответов),
  «Раса Ксеносов» (14 ответов); фрагмент каждого ответа = мини-анкета фракции,
  next = блок 7 «Является ли персонаж псайкером?» (кроме ответа «Псайкер
  Империума»: у него свои поля, он финиширует сразу).
- Блок 7: ответ «Да» несёт фрагмент «ПСАЙКЕРСКИЕ СПОСОБНОСТИ», «Нет» пустой;
  оба финишируют сборкой шаблона.
- Ядро анкеты едет фрагментом ответа «Самописный герой» корневого блока
  (шапка сервера при этом остаётся кастомной).
- Штаб: отдельный корневой блок «Должность» (4 ответа: Гейм-Мастер, Модерация,
  Лоровед, Анкетолог), фрагменты = мини-анкеты должностей; агитки — постами
  в каналах набора.
- Лимит фрагмента 1900 знаков: самая длинная мини-анкета ~450 — запас двойной.
